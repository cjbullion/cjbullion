# CJ Bullion site

## Deploy (for automatic stock to work)

Drag-and-drop does NOT always enable Functions.

Best way:
1. Create a free GitHub account
2. Upload this folder to a new repo
3. In Netlify: Add new site → Import from Git → pick the repo
4. Deploy

Then open once:
https://cjbullion.com/.netlify/functions/stock?reset=1

That sets round stock to 1.
